# 离线课程的阅读界面

## 首先服务长文理解

暖色纸面、较深正文、一个强调色、深色代码区是本案例的视觉特征，可在用户无其他要求时沿用。正文行宽控制在舒适范围，标题与层级清晰，表格负责比较，正文负责因果；不要为装饰减少内容。

建议起点：背景 #f7f3ec、面板 #fffdf9、正文 #302e2a、强调 #b9472e、代码 #20242e。中文使用本机可用字体回退；离线要求下不请求 Google Fonts，可内嵌有使用许可的字体。配色仍须检查对比度。

## 结构与维护

内容数据/章节 → 生成器 → 最终 HTML。样式、交互、源码证据清单与模拟数据分别维护，再内联构建，避免手改生成文件被覆盖。

最终 HTML 内嵌 CSS、JS、SVG 和必要数据，不依赖 CDN、在线渲染器或远程字体；联网链接可以存在，但不影响阅读。外部实验文件、独立流程图查看器、源码跳转不属于单文件内嵌范围时必须说明。

默认布局：固定章节导航与进度 → 顶部语言切换/打印 → 章标题和目标 → 本章小节目录 → 概览/流程 → 深入小节 → 源码与完整函数 → 应用题 → 完成与下一章。窄屏转换为可折叠导航与单列。

## 必要交互

- Python/JavaScript/并排：仅改变展示，不调用数据库，不把密钥放在页面。
- 复制：复制原始代码，成功与失败都给反馈；不支持剪贴板时给可选择文本。
- 术语：首次使用可点开，键盘焦点和触摸可用，Escape 关闭；浮层防止被 overflow 裁切。
- 进度：基于稳定章节 ID 保存；存储受限时仍能阅读。总数由数据计算，新章不会清除旧记录。
- 流程：单步、重置、节点详情；尊重减少动画偏好，不依赖自动动画解释顺序。
- 测验：每个选项解释判断依据，不以打分替代反馈。
- 打印：隐藏控制项，展开必要讲解/答案，代码与表格尽量不截断，保留来源。

不要把正文滚动强行吸附到整屏，长章会被困住。代码允许合理换行或局部横向滚动，不能造成整个页面横向溢出；并排代码在窄屏堆叠。正文路径和 URL 允许断行。

## 模拟交互的价值

改变块大小时应看到真实切分规则产生的不同 chunks；切换重排失败时，应看到原顺序保留和降级标记；无证据时应看到跳过生成。没有条件实现真实算法时明确固定演示，不能用按钮随机换分数冒充解释。

每个交互都回答一个问题：数据如何改变、顺序为何改变、错误如何传播、证据是否进入输出。普通展开面板与应用题足够的章节不必强塞动画。

## 浏览器交付验证

验证桌面和约 390px 窄屏、键盘、目录与深锚点、语言切换、复制、进度重载、测验、重置、打印、无外部网络依赖。DOM 存在不代表用户看见；关键页面用实际截图检查遮挡、溢出和字体。

追加章节后，已打开标签页可能仍持有旧 DOM。仅跳转 `#chapter-9` 不会重新请求 HTML。真正重新加载或使用 `?v=<build-id>#chapter-9`，核对侧栏、分母和正文。不要只给链接就宣布新章可见，也不要反复开许多重复页。

## Archify 与后备

有 Archify 且用户要求时，按其当前说明生成并验收。没有时使用自包含 SVG 配 HTML 节点说明；保留同等的函数定位、数据流、分支与错误解释。工具品牌不是教学质量前提。
