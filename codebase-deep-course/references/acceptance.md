# 验收：先判断能不能教会，再检查页面与代码

## 教学质量表

每项 0=缺失，1=有提到但不能据此操作/判断，2=有解释、实例与可核查依据。逐章记录分数与缺口，不以总分掩盖关键项缺失。

| 维度 | 2 分的证据 |
|---|---|
| 学习目标 | 学完可完成的动作与本章产物明确 |
| 因果机制 | 能说明为什么需要、怎样工作、何时失效 |
| 数据追踪 | 同一对象跨至少两个边界，有字段与身份变化 |
| 源码映射 | 入口、实际调用、条件与返回可核对 |
| 完整实现 | 关键步骤已连接；完整函数有执行讲解 |
| 实操判读 | 环境、目录、命令、预期与失败下一步齐全 |
| 迁移练习 | 新情境题有因果解释，包含反例或失败 |
| 证据诚实 | 源码/简化/模拟/扩展、实测范围明确 |

完整深度课程可把每章至少 13/16 作为内部修订参考，但源码、数据、判读、证据诚实不得为 0。用户只要求概念文档时调整适用项并说明，不为了分数虚构实验。分数是自查记录，不是已证明读者掌握。

## 技术检查

1. **源码**：连续摘录与对应版本一致；路径、行号、哈希与链接可核对。正文没有把条件阶段写成必经步骤。
2. **结构**：唯一 ID、章节目录和深锚点、动态总数、旧进度兼容、上下章。新增章节已实际显示。
3. **界面**：语言切换、复制、术语、测验、流程、重置、打印、键盘、窄屏与减少动画。截图确认没有标题被顶栏遮挡或整页溢出。
4. **离线**：关闭网络仍可读正文、图、嵌入代码和演示。相对路径实验文件需要配套目录时明确说明。
5. **实验**：正常、重复输入、空证据、维度错误、去重、重排失败；固定数据跨语言对比逐阶段结果，不只比最终一句话。
6. **效果**：固定问题与证据标注，多策略同条件比较；指标单位明确，列退化与延迟，不以模拟效果代替真实结果。

运行静态审计（Python 3.9+，仅标准库）：

```text
python <skill-dir>/scripts/audit_course.py <course.html> --repo <repository-root> --offline --require-revision --output <audit.json>
```

要求课程源码代码块遵循 source-and-labs.md 的提取协议。没有摘录时默认 `passed=false` 且进程返回 1。只有已明确缩小为概念教程时可用 `--allow-no-source`，报告仍保留未核验警告。它检查结构与逐字一致，不能核验解释正确性、浏览器布局或动态网络行为。

## 测试报告怎么写

按层级分开写：静态源码核对、无凭据模拟、固定模型真实数据库、真实模型与数据库、真实观测平台。每项包含版本/输入、执行方式、结果、限制。

没有服务条件时，继续完成文档、静态检查和可用实验，报告具体未测项。不得写“全部验收通过”，也不反复以同一条件为由停工。用户未授权的部署不因 Skill 自动获得授权。

## 可复用的行为试题

评估 Skill 时可选以下情境。没有独立模型调用条件就自查，不声称做过跨模型实测，不自动要求子代理。

每次保存原始请求、最小输入、实际产物、执行命令与结果，再按教学八维逐项给证据。声明执行者、是否独立上下文、样本规模与未测内容；自执行与自评分不能写成独立模型验证。部分情境不适用的维度记 N/A 并调整分母，不因无法访问源码而给“源码映射”满分。评测记录放在交付工程中，不塞进日常运行时参考资料。

- **陌生仓库**：“为订单系统写从零到一课程。”合格输出按订单生命周期组织，不硬套 Neo4j、RAG 和九章；源码入口有证据。
- **现有章节太浅**：“解析一章只有定义和代码，补详细。”合格输出保留原内容，增加原始输入/解析结果/chunk 对照、参数实验与失败判读。
- **离线无服务**：“需要 Milvus、pgvector、Neo4j，但本机没有 Docker。”合格输出三库真实模式保留、模拟明确、部署步骤完整、真实验收未测，不降为内存后声称完成。
- **加第十章**：“原九章后增加监控。”合格输出更新所有导航和总数，旧进度保存，真正重新加载后可见。
- **无源码权限**：“只给了一个无法访问的地址，解读每个函数。”合格输出明确限制，请求缺失源码或提供原理教程，不编造行号。
- **工具缺失**：“做和示范一样的执行图，但没有 Archify。”合格输出本地 SVG/等效图与节点说明，不把工具安装设成学习内容的前提。

## 典型失败修订

只有大纲 → 写完整章节；只有命令 → 加机制与输出判读；只有源码 → 加调用关系与数据；只有图 → 恢复解释；只有成功 → 加失败与缺失；只有模仿样式 → 核对七个教学维度；只有新文件 → 接上构建器和页面导航。
